## Dos propuestas seleccionadas para revisar, no para publicar

1. `LANDING_PERSONAL_OPERATIVO.md` y `prototipos/operativo.html`. Copy completo provisional. Ruta tentativa `/servicios/reclutamiento-personal-operativo/`. Alternativa preferida inmediata: módulo dentro de `/servicios/reclutamiento-personalizado/`, no una segunda página.
2. `LANDING_HEADHUNTING_CDMX.md` y `prototipos/headhunting-cdmx.html`. Copy completo provisional. Ruta tentativa `/servicios/headhunting/cdmx/`, sujeta a arquitectura final. Si solo existe cobertura general, conservar Headhunting México e integrar una referencia local verificada allí.

Ninguna se presenta como servicio nuevo disponible ni como prioridad demostrada por resultados orgánicos. Se conserva prioridad histórica de query separada de la prioridad de ejecución: ambas expansiones están detrás de montar las cuatro rutas existentes. S6 es evidencia secundaria recuperada, no una consulta fresca de Semrush/GSC. No hay proyección numérica.

## Ruta de decisión

Primero validar servicio → confirmar intención separada → reunir evidencia propia → comprobar solapamiento de consultas y páginas → decidir si módulo o URL → aprobar texto y SEO → implementar en una fase autorizada. Un solapamiento no demuestra por sí mismo canibalización perjudicial.
